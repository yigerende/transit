# 渠道自动暂停开关

自动化策略编辑页在「自动远端动作」下面增加「允许暂停渠道」，新建策略、分组设置向导及升级前已有策略均默认关闭，保存后再次打开保留选择。

- 关闭：探活失败只更新健康结果，用于已开启的分组倍率/健康优先级排序。不进入「探活暂停」、观察或暂停冷却，不降低转发权重，也不自动停用上游渠道。
- 开启：配合「自动降级」允许按失败阈值和硬失败规则进入本地暂停；还需开启「自动远端动作」，才会实际修改 Sub2API 账号启停状态或 NewAPI 渠道状态/权重。
- 关闭后已有的自动暂停按降级状态显示，调度清除暂停冷却；失败退避和每日预算继续生效。系统此前接管停用的渠道按保存的原状态恢复；存在人工修改冲突时保持原有保护。人工禁用状态不受影响。
- 分组优先级配置独立生效，关闭暂停开关不会自动开启优先级排序。
- 同一渠道重叠策略以不允许暂停为先；不同模型共用渠道时，任一生效模型策略关闭暂停，其他模型也不能借此停用整个渠道。
- 后端在探活返回及批次远端动作前检查最新权限，关闭开关后在途探活不能沿用旧的暂停授权。降智检测继续只记录检测结果。

持久化字段：`auto_suspend_enabled`，API 字段：`autoSuspendEnabled`，缺省值为 `false`。
