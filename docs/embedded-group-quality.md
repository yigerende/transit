# 分组降智检测（嵌入功能）

入口：**嵌入功能 → 分组降智检测**，管理页 `/admin/group-quality`。

界面采用“观测目录 + 当前对象工作台”：左侧搜索与切换分组模型，右侧展示响应趋势、糖果/鹈鹕环形结果、按类型切换的历史，以及大画布与近期作品索引。手机端目录变为横向选择。

创作样本室的大图和详情保留原始动画，近期作品缩略图在完成首帧绘制后转为静态预览，支持 Canvas 画作和 CSS 动画。缩略图依次生成并使用有上限的内存缓存，生成后移除脚本、禁用动画并收紧沙箱；手机端不创建隐藏缩略图。主图优先加载，切换作品仍展示对应的完整动画。

每个检测项选择一个 Sub2API 分组和模型。展示名称、API 降智请求基础地址、三类自动检测开关、间隔与超时均单独保存，不读取或修改原分组健康/渠道自动化策略。初始自动检测全部关闭，可直接手动检测；自动检测开启后不依赖页面打开。

| 检测 | 路径和模型 | 默认间隔 / 超时 |
| --- | --- | --- |
| 探活 | 分组 Key 请求工作区网关；可选轻量请求、算术检测、流式首字 | 60s / 20s |
| API 糖果 | 满血公开 API；使用所选模型 | 300s / 180s |
| API 鹈鹕 | 满血公开 API；当前 API 固定使用 `gpt-6-astra`，页面明确标注实际模型 | 1800s / 600s |

首次获取模型或检测时自动获取/创建绑定分组的 `embed-group-*` Key。Key 命名稳定，可复用，但与原分组健康的配置独立。Key 仅用于请求，不写入新表或返回给浏览器。API 降智基础地址可覆盖为公开 HTTPS 域名，Key 仍来自原分组；探活仍访问原工作区地址。

手动请求只入队并立即返回 202；后台保存完成记录，前端默认 15 秒刷新。三类检测分别拥有两个 worker，鹈鹕长任务不会占用探活名额。PostgreSQL 原子领取和 12 分钟租约避免同一项重叠；单次任务总时限 650 秒。异常退出的任务可在租约到期后重试。间隔以开始时间为基准；执行超过间隔时不重叠、不补发积压次数。

嵌入设置可配置“每类历史保留条数”（1–1000，默认60），每个检测项的探活、糖果、鹈鹕分别计算，包含手动和失败记录。保存后立即删除超出数量的最早记录及对应作品；每次检测完成也自动清理。未公开或关闭自动检测的项目同样遵守保留设置。删除不可恢复，调大不会找回旧记录。迁移 `000038_embed_monitor_history_limit` 默认延续原来的60条上限。

页面展示和统计使用保留历史中最近最多60次，列表不随存储上限无限增长。延迟为当前探活方式最近5次成功的均值；糖果和鹈鹕通过率只统计有效判定，请求异常单独计数。列表省略完整作品、答案和诊断，按需读取详情；作品预览延迟加载，HTML使用不具备同源权限、禁止联网的sandbox iframe。详情提供起止时间、实际模型、耗时及接口可用的Token用量。费用沿用满血网页参考价估算，不代表实际账单。

**嵌入设置**独立控制只读发布，默认关闭。可设置标题、复制链接/iframe 代码、重置链接。公开接口仅提供查询，不能发起检测或改配置，不返回网关地址、Key 或内部错误详情。持有链接者能读取所发布的历史和作品，关闭发布/重置链接后旧访问失效。

可在“向用户展示的检测项”中逐项勾选分组与模型，支持全选/全不选，点击“保存嵌入设置”生效。未勾选项保留后台检测、配置和历史，但不会出现在公开列表中，公开详情接口也不返回其历史和作品。全部取消时显示“暂无公开检测项”。升级保留现有检测项的公开状态；升级后新建项默认不公开，需要明确勾选。迁移 `000037_embed_monitor_visibility.sql` 保存每个检测项的公开状态。

公开嵌入页默认使用浅色主题，不改变后台保存的主题偏好；需要深色时可在嵌入链接后添加 `&theme=dark`。页面注明糖果与鹈鹕检测由 [manxue.ai](https://manxue.ai) 提供。

嵌入设置中的“一键清空检测历史”经确认后删除当前工作区这套检测的全部探活、糖果、鹈鹕历史及作品，保留检测项、自动任务和嵌入配置；不影响原分组/渠道监控或其他工作区。进行中的任务和后续检测会继续产生新记录。此操作仅管理员可用，公开嵌入页不提供清空接口。

数据库迁移 `000036_embed_group_monitor.sql` 新增四张独立表。删除工作区时清理配置，任务/历史通过外键级联删除；不改变既有探活表。编辑检测项时分组和模型不可变，更换时新建检测项，避免混合历史。当前检测项右上角“设置”旁有“删除”按钮，确认后移除该项、后续检测任务及历史作品，不删除 Sub2API 原分组。已发出的请求可能仍完成，但结果不会重新写回；公开嵌入页不显示删除按钮。
